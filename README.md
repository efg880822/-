# 我們的台灣旅遊地圖

以 Instagram 🐑🫂 珍藏匯出的資料建立的 GitHub Pages 靜態網站。

## 功能
- 台灣縣市地圖點選
- 🍜 美食 / 📍 景點 / 🏨 住宿
- 搜尋
- ❤️ 已去過
- ⭐ 想去
- 點擊「開 IG」回到原始貼文或 Reel
- 已去過/想去狀態儲存在使用者自己的瀏覽器 localStorage，不會把 IG 密碼或資料送出。

## GitHub Pages
將 `index.html` 與 `data.json` 上傳到 GitHub repository，Settings → Pages → Deploy from branch → main / root。
